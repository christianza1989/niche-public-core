# ChatGPT įgūdžiai iš AI Agents Library

Šaltinis: https://www.aiagentslibrary.com/skills/chatgpt/
Surinkimo data: 2026-09-26

Šiame aplanke yra 48 puslapyje nurodyti įgūdžiai. Kiekvienas įgūdis turi atskirą aplanką su:

- `SKILL.md` — įgūdžio failas. 43 failai paimti iš viešai pateikto SKILL.md kodo puslapyje. 5 failai vietoje supakuoti iš viešai pateikto prompto, nes tų puslapių SKILL.md kodas nebuvo viešai pateiktas.
- `PROMPT.md` — puslapyje viešai pateiktas kopijuojamas promptas.

`index.csv` yra visas sąrašas ir kiekvieno `SKILL.md` kilmė. Failai išsaugoti peržiūrai; jų turinys nėra įdiegtas ar paleistas.
